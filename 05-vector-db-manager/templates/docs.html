API 接口文档

模型管理

方法路径说明
GET/api/models列出所有已加载的 Embedding 模型
POST/api/models/load加载或切换模型。Body: {model_name, provider_type, api_key?, api_base?}

集合管理

方法路径说明
GET/api/collections列出所有 Collection
POST/api/collections创建 Collection。Body: {name, description}
GET/api/collections/{name}获取 Collection 详情
DELETE/api/collections/{name}删除 Collection
POST/api/collections/{name}/clear清空 Collection 文档

文档导入

方法路径说明
POST/api/import/files批量导入文件。Body: {collection_name, file_paths[], chunk_size, chunk_overlap, chunk_strategy}
POST/api/import/directory导入目录。Body: {collection_name, dir_path, chunk_size, chunk_overlap, chunk_strategy}
POST/api/import/upload上传文件导入。FormData: {collection_name, chunk_strategy, chunk_size, files[]}

搜索与对比

方法路径说明
POST/api/search相似度搜索。Body: {collection_name, query, top_k, threshold, metadata_filter?}
POST/api/compare多索引对比搜索。Body: {collection_names[], query, top_k}

分块测试

方法路径说明
POST/api/chunk/test测试分块效果。Body: {text, chunk_size, chunk_overlap, chunk_strategy}
GET/api/chunk/strategies列出所有分块策略

系统

方法路径说明
GET/api/health健康检查
GET/api/statistics系统统计信息
GET/docsFastAPI 自动生成的 Swagger 文档
